# Инструкция по работе с Telegram-ботом Factory Battle TG

Добро пожаловать в игру Factory Battle TG! Этот бот позволяет вам участвовать в экономической игре прямо через Telegram.

## Основные команды бота

### /start
Запускает бота и регистрирует пользователя в системе. После этой команды вы сможете создавать и присоединяться к игровым комнатам.

### /create_room
Создает новую игровую комнату, в которой вы будете лидером. В комнате могут играть несколько участников.

### /join_room [код_комнаты]
Присоединяется к существующей игровой комнате по коду комнаты. Замените `[код_комнаты]` на идентификатор комнаты, к которой хотите присоединиться.

### /leave_room
Покидает текущую игровую комнату.

### /start_game
Запускает игру в текущей комнате. Игру может начать только лидер комнаты, и в комнате должно быть минимум два игрока.

### /status
Показывает текущий статус игры и информацию о комнате.

### /help
Выводит список доступных команд и краткое описание каждой.

## Как играть

1. Отправьте команду `/start` для регистрации.
2. Создайте новую комнату с помощью `/create_room` или присоединитесь к существующей через `/join_room`.
3. Когда в комнате будет минимум два игрока, лидер может запустить игру командой `/start_game`.
4. Следуйте инструкциям бота для участия в игровом процессе.
